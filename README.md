# Overview

This repository provides access to the image sources used in the experimental validation of JPEG artifact removal for synthetic image detection.

The study investigates whether suppressing JPEG compression artifacts can improve existing detectors **without retraining their weights**. We evaluate three restoration methods (DnCNN, FBCNN, and SwinIR) with detectors based on source fingerprints, learned residual cues, and CLIP representations.

The experiments use real photographs and images from five synthetic sources: **DALL·E 3, FLUX.1-dev, FLUX.2-dev, Stable Diffusion 1.4, and Stable Diffusion 3.5**.

### Real images

The real-image subset used in the paper was obtained from **[RAISE](https://loki.disi.unitn.it/RAISE/index.php)** [1]. We selected 1,500 images in TIFF format and extracted centered **1024 × 1024** crops for the experiments.

Please obtain the original images through the RAISE website and follow its [download instructions](https://loki.disi.unitn.it/RAISE/guide.html).

### DALL·E 3 images

The DALL·E 3 images were extracted from OpenAI's **[DALL·E 3 evaluation samples repository](https://github.com/openai/dalle3-eval-samples)** [2]. The experimental subset contains 1,500 images at **1024 × 1024** resolution, generated from captions in the MS-COCO 2014 validation set.

The upstream repository contains outputs from several models. Select the **DALL·E 3 samples**, rather than treating all repository images as DALL·E 3 outputs.

### Other synthetic sources

The images in the four uploaded archives (**FLUX.1-dev, FLUX.2-dev, SD14, and SD35**) were generated by the authors using the prompts collected in [`prompts/8k_coco.txt`](https://github.com/openai/dalle3-eval-samples/blob/main/prompts/8k_coco.txt) from OpenAI's DALL·E 3 evaluation samples repository. These prompts are based on captions from the MS-COCO 2014 validation set. For each source, the paper uses 1,500 images randomly selected from a larger generated collection.

Synthetic images were originally stored in **PNG** format. FLUX.1-dev, FLUX.2-dev, and SD35 images have a resolution of **1024 × 1024**, while SD14 images have a resolution of **512 × 512**. They were used at their native resolutions.

# Experimental Dataset and Protocol

The paper uses **9,000 images**, equally distributed across the six sources. Each source is divided into two non-overlapping subsets:

| Subset | Images per Source | Total Images | Purpose |
|---|---:|---:|---|
| Reference | 500 | 3,000 | Reference fingerprint estimation |
| Test | 1,000 | 6,000 | Experimental evaluation |
| **Total** | **1,500** | **9,000** | |

These counts describe the experimental subset reported in the paper, rather than the sizes of the original external datasets or the larger generated collections.

For the compression experiments:

- Real and synthetic images were JPEG-compressed using **Pillow 10.0** at **QF ∈ {75, 60, 40}**.
- The compressed images were processed with **DnCNN, FBCNN, and SwinIR** for JPEG artifact removal.
- Detection was evaluated on the original, compressed, and restored images using the same detector weights.
- For fingerprint-based experiments, reference fingerprints and query images were evaluated under the processing conditions described in the paper.

The DnCNN restoration model was trained using an additional, non-overlapping set of 2,000 natural images from RAISE. These training images are separate from the 9,000-image reference/test dataset above.

See Sections 3-5 of the [paper](https://gpsc.uvigo.es/wp-content/uploads/2026/10/DFF2026_jcperez_dvazquez_fperez.pdf) for the restoration configurations, evaluation protocol, and results.
